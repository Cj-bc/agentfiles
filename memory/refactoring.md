## 一括置換の正規表現は連番付き識別子・PascalCase埋め込み参照を取りこぼす
`\bold\b` は `old01`（数字が続く＝word boundary が無い）にはマッチしない。番号付きのテスト関数名
(`def old01_...`)、モジュール宣言などの PascalCase 識別子 (`mod X.Old`)、camelCase の中に埋め込まれた
PascalCase 参照 (`isTheSameAsOld`) は取りこぼすので、大文字始まりのパターンでも別途探して手動で直す。

## リネームはスコープを超えない — 対応する概念が無いものは足さない
「識別子を X に揃えて」という依頼は既存のものの改名であって、対象（他言語の API や別の設計等）に
あって自分たちに無い機能を新設する話ではない。対応する概念が無いものは、既存の語彙・命名パターンに
合わせて改名するに留め、新しい機能は足さない。
