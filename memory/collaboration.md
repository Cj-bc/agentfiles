## 似た名前のブランチは「複数モデルの出力比較」用のことがある — 一切参照しない
同じリポジトリに似た名前のブランチ (`claude/<task>-<suffix>` など) や、関連する PR が複数存在することがある。
これは他のセッションの試行錯誤の残骸とは限らず、**複数のモデルに同じタスクを独立してやらせて出力を
比較するため**に意図的に用意されていることがある。その場合、そのブランチや PR の diff・コミット・
コメント内容は一切参照せずに、自分だけの判断で独立して作業すること。参照すると比較の前提が崩れる。

## リモートのベースブランチは作業前後で確認する
作業対象のベースブランチ（例: `develop`）が、自分が最初に見た時点から変わっていないか
（他の PR が先にマージされて内容が変わっていないか）を、作業開始前と PR 作成後の両方で確認する。
