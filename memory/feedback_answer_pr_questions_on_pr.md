name: Answer PR questions on the PR
description: PR のコメントで意見を尋ねられたら、セッション側だけでなく PR にもコメントで答える。
type: feedback
---

PR のコメントで意見や判断を尋ねられたら、その PR にコメントで返答する。セッションでユーザーに伝えるだけで済ませない。

**Why:** 2026-11-12、flix-agent の PR でオーナーが「opengrep か comby を使うのはどうですか？」とコメントした。そのときはセッション側にだけ回答し、PR には書かなかった。ユーザーから「PR のコメントで意見を尋ねられた場合、PR にコメントするように」と指示された。

**How to apply:**
- 質問の主がユーザー本人でも、PR 上で答える。議論の経緯が PR に残るようにするため。
- 判断がまだ決まっていない場合は、PR には意見と推奨を書き、決定はユーザーに委ねる。決まったら、その結論も PR に書く。
- 投稿前には [Review public comments for security](feedback_public_comment_security.md) に従って読み直す。
