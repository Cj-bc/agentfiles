# changelog-profile — <リポジトリ名>

`/update-changelog` スキルが読むリポジトリ固有の設定。**このファイルには履歴文書の書式と
分類規則だけを置く**。コーディング規約や既知の例外は書かず、リポジトリの規約ファイル
(`AGENTS.md` / `CONTRIBUTING.md` など)を指すだけにする(二重管理を避けるため)。

## 1. 対象ファイル

| 項目 | 値 |
|---|---|
| 既定の対象 | `<repo-root>/CHANGELOG.md` |
| 文字コード | UTF-8 (BOM 無し) |
| 改行 | LF / CRLF |
| 言語 | 日本語 / English |

引数でパスが渡された場合はそちらが優先。相対パスはリポジトリルート基準で解決する。

## 2. 書式

```
# <バージョン>          ← 最上位が未リリース節。名前: `# unreleased`
## added / changed / fixed
+ エントリ
```

| 項目 | 規則 |
|---|---|
| 未リリース節の見出し | `# unreleased` |
| 節の名前と順序 | `added` → `changed` → `fixed` |
| 箇条記号 | `+ ` |
| 追記位置 | 該当節の先頭(新しいものが上) |
| 1 エントリの長さ | 既存の粒度に合わせる |

## 3. エントリの接頭辞

| 接頭辞 | 使う場面 |
|---|---|
| (例) `開発:` | 開発者にしか見えない内部変更・テスト・ドキュメント |
| (例) `feat:` | アプリの挙動・見た目として現れる変更 |
| (例) 無印 | 利用者向けの不具合修正 |

## 4. コミット種別 → 節の対応

| コミット種別 | 節 | 備考 |
|---|---|---|
| `feat` | added / changed | 新規は added、既存の変更は changed |
| `fix` | fixed | |
| `refactor` | changed | |
| `test` | changed | 関連機能のエントリに束ねることが多い |
| `docs` | changed | |
| `chore` | 原則書かない | 観測できる効果が無いもの |

## 5. 参照 ID の書式

| 種類 | 書式 | 例 |
|---|---|---|
| issue | `[#<n>]` | `[#102]` |
| 課題管理 | | |
| ADR | | |

## 6. 人間の確認が必要な項目の目印

| 目印 | 使う場面 |
|---|---|
| (例) `**要目視確認**` | 見た目・タイミングの変化 |
| (例) `**差し替えが必要**` | 仮アセットのまま |
